# Public-source ingestion

Only URLs readable without registration, payment, API keys, owner contact or external waiting are accepted.

`Public URL → metadata → checksum → access-policy gate → parser → normalized records → candidates → collision audit → passport candidate`.

The gate supports `OPEN_REUSE_ALLOWED`, `OPEN_REFERENCE_ONLY`, `PUBLIC_WITH_ATTRIBUTION`, `PUBLIC_NO_REUSE_TERMS`, and rejects `REJECTED_CLOSED_SOURCE`. Full normative documents are not copied into Git. Jurisdiction, clause/page, retrieved date and supported/unsupported claims remain attached to every derived record.
